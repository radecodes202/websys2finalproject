# Test Plan

## Current Regression Coverage
Automated Django `TestCase` suites covering:
- **Auth & dashboard** — login, self-registration approval flow, dashboard summary cards (product count, today's sales, low stock, alerts, profit, pending POs)
- **Role-based access control** — anonymous redirects and per-role allow/deny across the dashboard, categories, products, suppliers, customers, reports, pending users, and admin-only registration
- **Admin-only user registration** — self-register form excludes the `admin` role; admins can create new admins who are immediately approved
- **Security settings** — session/CSRF cookie flags, SameSite, nosniff, XSS filter, referrer policy
- **Audit app** — the dedicated `audit/` app is exercised via its model/service tests and is part of the project structure
- **Product CRUD** — create + list with search and filtering
- **Purchase-order receiving** — receiving increases stock, creates a `purchase` `StockMovement`, and transitions the PO to `received`
- **Sale checkout** — completing a sale deducts stock, creates a `sale` `StockMovement`, and guards against overselling
- **Alerts** — low-stock and near-expiration (`expiring`, configurable threshold) alerts generated by `Product.create_alerts()`
- **Supplier payments** — supplier payment balance and history are recorded
- **Reports** — sales report with period filters, sales history with pagination, inventory valuation, stock movement, supplier payments outstanding, profit & loss summary, PDF and Excel export
- **Barcode scanner** — barcode search in POS
- **Stock adjustment** — manual stock adjustment with reason codes

## Test Inventory
- `accounts.tests` — auth, dashboard, role-based access, admin registration, security settings
- `product.tests` — product CRUD, purchase order receiving, sale checkout, alerts, stock adjustment, barcode search
- `supplier.tests`, `customer.tests`, `category.tests` — regression tests for CRUD and access checks
- `reports.tests` — report views and exports
- `audit.tests` — audit trail model and service tests

## Execution Commands
- Full suite (80 tests):
  `py manage.py test accounts supplier customer category product reports audit`
- Per app:
  - `py manage.py test accounts.tests`
  - `py manage.py test product.tests`
  - `py manage.py test supplier.tests`
  - `py manage.py test customer.tests`
  - `py manage.py test category.tests`
  - `py manage.py test reports.tests`
  - `py manage.py test audit.tests`

# User Manual

## Roles
- Admin: full administration access
- Manager: inventory, supplier, and reporting access
- Cashier: POS and sales tasks
- Inventory Staff: product and stock receiving

## Common Tasks
1. Log in to the system.
2. Use the dashboard summary cards to review current status.
3. Manage categories, products, customers, and suppliers from the list screens.
4. Receive purchase orders and update stock through the receiving flow.
5. Use the reports view to review sales and inventory data.
